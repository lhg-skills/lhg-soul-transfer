# 记忆仓 · README 模板

> 把这份模板复制为你记忆仓库的 README.md，把里的占位符换成你自己的内容。
> 注意：这是**模板**，示例内容均为虚构，不要填入真实个人信息。
> 阅读前提：先读完灵魂仓（``）并完成报到，再读本仓。

# 的记忆仓

这里存放"我们共同经历了什么"——长期记忆、每日日志、人物、群体、知识库。天天生长，只增不减。

## 给新 agent 的阅读顺序（按顺序读完，不要跳）

1. `MEMORY.md` —— 长期记忆正文： durable 的事实、偏好、承诺、项目（先读这个建立骨架）
2. `memory/bank/` —— 知识库：经验沉淀（experience）、观点（opinions）、反思（reflections）、世界观（world）
3. `memory/people/` —— 人物：先看 `INDEX.md`，再按与用户的亲近度读人物卡
4. `memory/groups/` —— 群体：先看 `INDEX.md`，再读群体卡
5. `memory/当日日期.md` —— 当天日报（了解最近在忙什么）
6. `memory/过去 7 天的日报` —— 倒序读 7 天（把握最近的上下文和情绪）
7. `alignment/ALIGNMENT_SYNTHESIS.md` —— 关系合成（和灵魂仓是同一份，这里放一份方便离线读）

> 日报只读最近 7 天 + 当天，不要通读全部历史——太长了，需要时再按日期检索。

## 读完后如何报到

灵魂仓报到时你已经报过一次了。读完记忆仓后，追加一次"记忆报到"：

1. 用**三句话**复述：用户最近在忙什么（一句话）、最重要的长期承诺是什么（一句话）、你现在最该注意什么（一句话）。
2. 然后问用户："记忆已载入完毕。你想先从哪件事开始？"

## 维护约定

- 本仓天天长：每日日志、人物更新、记忆正文修订，每天同步一次。
- 同步前跑密钥扫描（见主 skill 第 4 步），命中即中止。
- 本仓为私有仓库，不公开、不进 skill 市场。日报里可能有最私密的日常，更要守住。
- 删除文件要谨慎：记忆是"只增不减"的，删之前问用户。
