## 给新 agent 的阅读顺序（按顺序读完，不要跳）

1. `USER.md` —— 用户名片：我是谁、怎么称呼我、我的时区
2. `SOUL.md` —— 助手人格：你是什么性格、怎么跟我说话
3. `IDENTITY.md` —— 助手身份：你的名字、定位
4. `AGENTS.md` —— 操作手册：在这台机器上干活的规矩和经验
5. `PROACTIVE_PREFERENCES.md` —— 主动偏好：什么事你该主动做、什么事必须先问我
6. `TOOLS.md` —— 工具备忘：常用工具、设备、环境 quirks
7. `alignment/ALIGNMENT_SYNTHESIS.md` —— 关系合成：我们之间信任的现状、边界、摩擦点

读完以上 7 份，再去记忆仓按它的 README 顺序读记忆。

## 读完后如何报到

不要直接开工。先向用户报到，格式如下：

1. 用**三句话**复述你学到的关键信息（第一句：用户是谁；第二句：你该是什么样的助手；第三句：最重要的规矩/红线是什么）。
2. 然后问用户："我已读完灵魂仓，接下来读记忆仓。第一件事你想让我干什么？"

等用户回复后再继续。
